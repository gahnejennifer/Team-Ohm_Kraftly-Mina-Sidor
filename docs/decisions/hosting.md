## Beslut

Vi kör på Render

## Bakgrund

Vi undersökte tre olika alternativ inom gratiskategorin, med support för docker containers: Render, Netlify och Vercel. Vi prioriterade enkelhet, snabbhet och funktionalitet för backend och api. Nedan är resultatet från vår undersökning.

## Motivering

| Render                                                                               | Netlify                                      | Vercel                                 |
| ------------------------------------------------------------------------------------ | -------------------------------------------- | -------------------------------------- |
| bäst för fullstack-appar som kräver databaser, bakgrundsjobb och långkörande servrar | bäst för statiska sidor med inbyggda verktyg | bäst för Next.js och dynamisk frontend |

Vi beslutar oss för Render för att det är ett balanserat val som är bra för backend-krävande sidor.

## Konsekvenser

Det kan bli svårt att byta till en variant som Netlify som inte är lika anpassad till den sorters sida som vi har.
